## 为什么搭建博客

写博客是一种很好的学习方式。通过写作，可以整理和巩固所学知识，记录解决问题的过程，与他人分享经验和思考，同时也有助于建立个人技术品牌。

## 技术选型

本博客使用以下技术栈搭建：

| 工具 | 用途 |
|---|---|
| **Hexo** | 静态博客框架 |
| **NexT 主题** | 简洁技术风主题 |
| **GitHub Pages** | 免费静态网站托管 |
| **GitHub Actions** | 自动化构建部署 |

## 如何写新文章

在本地执行以下命令即可创建新文章：

```bash
hexo new "文章标题"
```

文章使用 Markdown 格式编写，写完后推送到 GitHub，GitHub Actions 会自动构建并部署。
